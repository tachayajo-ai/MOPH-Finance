# สมุดเรียนงบ รพ. — แอปเรียนงบการเงินโรงพยาบาลสำหรับงานประกันสุขภาพ

แอปเรียนด้วยตนเอง เป้าหมาย: ภายใน 90 วันหลังเริ่มงาน (1 ธ.ค. 2569) อ่านงบการเงิน รพ. 1 แห่ง แล้วบอกได้ภายใน 30 นาทีว่า "ป่วยตรงไหน เพราะอะไร ต้องแก้อะไร" — สเปกเต็มอยู่ที่ [APP_SPEC.md](APP_SPEC.md)

## ใช้งาน

เปิดไฟล์ `dist/index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้ ไม่ต้องติดตั้ง ไม่ต้องมีอินเทอร์เน็ต) — ใช้ได้ทั้ง PC และมือถือ

| เมนู | ทำอะไร |
| --- | --- |
| หน้าหลัก | แผนเรียน 3 สัปดาห์ + 90 วัน, นับถอยหลังวันเริ่มงาน, ความคืบหน้า |
| ตำรางบการเงิน | บทที่ 0–8 จาก `content/textbook.md` · ติ๊กแบบฝึกและบทที่อ่านแล้ว |
| คู่มือประกันสุขภาพ | 8 บท + ภาคผนวก (กองทุน, DRG/AdjRW/CMI, เคลม/ติด C, Planfin/Risk, ม.41, สิทธิซ้อน, หนังสือราชการ) |
| อภิธานศัพท์ | 260 คำ ค้นหาและกรองตามหมวด |
| Ratio + Risk Score | กรอกตัวเลขจากงบ → CR, QR, Cash, NWC, NI + จำลองคะแนน 0–7 (ป้าย "จำลองเพื่อการเรียน ไม่ใช่ผลทางการ") |
| กรณีศึกษา 21 รพ. | ข้อมูลจริง จ.อุดรธานี ณ มิ.ย. 69 จากสไลด์ กวป. ก.ค. 69 (ชื่อ รพ. เปลี่ยนเป็นรหัส รพ.01–21): ฝึกทาย Risk Score รายมิติ, ตารางรวมเรียงได้, ดูราย รพ. + กราฟแนวโน้ม NWC/เงินบำรุง, ส่งต่อไปร่าง Action plan |
| ACP Cash Unlock | คำนวณ ACP และเงินสดที่ปลดล็อกได้ ≈ (รายได้ต่อปี ÷ 365) × วันที่ลด + คัดลอกประโยคนำเสนอ |
| แบบทดสอบ | 3 ชุด: แนวคิด (26 ข้อ) · เกณฑ์ตัวเลข (สร้างจาก criteria.json) · ศัพท์ + แบบทดสอบตนเอง 8 ข้อ |
| Flashcards | 260 คำ เริ่มจาก 30 ตัวย่อที่ต้องจำก่อน |
| Action plan | ฟอร์ม 7 คอลัมน์ → คัดลอกวางใน Word/Excel หรือดาวน์โหลด CSV |
| สำรองความคืบหน้า | ส่งออก/นำเข้าไฟล์ .json (ข้อมูลเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น) |

ใช้บนแท็บเล็ต/มือถือ: เปิดลิงก์ artifact บน claude.ai (หรือคัดลอก `dist/index.html` ลงเครื่อง) — ความคืบหน้าเก็บแยกรายเครื่อง ใช้เมนู "สำรองความคืบหน้า" ย้ายข้อมูลระหว่างเครื่อง

## กฎที่แอปบังคับ

- **PDPA** ไม่มีช่องกรอกชื่อผู้ป่วย/HN/AN/เลขบัตรประชาชน · ฟอร์ม Action plan ตรวจรูปแบบเลข 13 หลัก, HN/AN, คำนำหน้า+ชื่อ-สกุล แล้วปิดปุ่มคัดลอก/ส่งออกจนกว่าจะลบ · `tools/build.py` ตรวจเนื้อหาก่อน build
- **เกณฑ์ทุกตัวมีแหล่งอ้างอิง** `[S1]`–`[S7]`, `[M1]`, `[K1]` (กวป. ก.ค. 69 — เกณฑ์ 7 Plus รายช่องเป็นค่าอนุมาน ติดป้ายไว้) และป้าย "ตรวจกับหนังสือสั่งการปีงบปัจจุบันก่อนใช้งานจริง" · build จะล้มถ้าเกณฑ์ไม่มี `src`
- **ตัวเลขฝึกติดป้าย "ตัวเลขสมมติ"** ทุกจุด
- เกณฑ์แยกไฟล์ `data/criteria.json` — แก้ทุกปีงบได้โดยไม่แตะโค้ด

## อัปเดตเกณฑ์ทุกปีงบ

1. แก้ `data/criteria.json` (ใส่ `src` ที่ชี้ไปยัง `sources` ทุกครั้ง)
2. รัน

```bash
python3 tools/build.py
```

## อัปเดตเนื้อหา

- ตำรางบการเงิน: export Claude Doc เป็น Markdown ทับ `content/textbook.md` แล้วรัน build
- คู่มือ/อภิธานศัพท์: วาง .docx ฉบับใหม่ใน `sources/` (ชื่อไฟล์ตามที่ `tools/import_docx.py` กำหนด) แล้วรัน (ต้องมี pandoc + python-docx)

```bash
python3 tools/import_docx.py
```

## โครงสร้าง

```
content/textbook.md      ตำรางบการเงิน (export จาก Claude Doc 12 พ.ย. 2569)
content/manual.html      คู่มือระบบประกันสุขภาพ รพ.รัฐ (แปลงจาก sources/*.docx)
data/criteria.json       เกณฑ์ Ratio / Risk Score / Efficiency / แหล่งอ้างอิง
data/quiz.json           คำถามแนวคิด
data/glossary.json       ศัพท์ (แปลงจาก sources/*.docx)
data/concept_cards.json  Flashcards แนวคิดบทที่ 3–7 (หมวด 0.3–0.7)
data/casestudy.json      ข้อมูล 21 รพ. จาก กวป. ก.ค. 69 — ชื่อ รพ. เป็นรหัส (ไม่เก็บตารางเทียบชื่อใน repo)
src/                     template, CSS, JS (vanilla ไม่มี dependency)
tools/                   build.py, import_docx.py
dist/index.html          ไฟล์ใช้งานจริง (สร้างจาก build)
```

ข้อจำกัด: แหล่งอ้างอิงทั้งหมดเป็นเอกสารนำเสนอ/รายงานของหน่วยงาน สธ. ที่เผยแพร่ ไม่ใช่ประกาศฉบับทางการ — ต้องอัปเดตเกณฑ์ปีงบ 2570 เมื่อได้หนังสือสั่งการจริง
